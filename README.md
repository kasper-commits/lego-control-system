# LEGO Control System

An open-source modular system to bring your LEGO city to life.

## Why I built this
I want my train switches to be easy to control **without touching them**.  
With this project, you can control switches, traffic lights, and house lights remotely.

## Goal
My goal is to make simple modules that are easy to use.  
This is for people who want LEGO city automation, including people who cannot build everything themselves.

## Main Control Box
The control box will have:
- a TFT display
- 20 buttons

You can connect one module per button, or assign multiple buttons to one module when needed.

## First Modules
- Main module (core control)
- Train switch module (first hardware module)

### Train Switch Module Specs
- up to 2 servos
- up to 4 light poles
